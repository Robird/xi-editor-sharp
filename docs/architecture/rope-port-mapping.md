## [RPM-Actions] Open Actions
<a id="RPM-Actions"></a>
1. **Lock canonical hash verification into default scripts** – Treat `python scripts/verify_fixture_manifest.py --manifest tests/xi.Core.Tests/Fixtures/fixtures.manifest.json` as a non-optional tail step inside both `scripts/refresh_serialization_fixtures.ps1` and `python scripts/refresh_all_assets.py --only stage-d-fixtures`, fail the run if hashes drift, and document the `-SkipManifestVerification` escape hatch + remediation inside `[StageD::FixtureFlow]`/`[Fixture-Manifest]` (`[TS-B3]`).
2. **Plumb StageDDescriptorInspector output through QA CLI + refresh tooling** – Pipe the Inspector CLI summary (counts, payload hashes, typed digests) into `[QA-IngestionSmoke]`, `refresh_all_assets.py`, and the Stage D CLI adapter so QA dashboards can diff loader/hydrator output against canonical Inspector evidence before merges (`[TS-B3]`, `[TS-B5]`).
3. **Capture Grapheme iterator CLI trace + loader hook** – Add CLI logging to the Rust exporter and land a C# loader that hydrates `GraphemeDescriptor` DTOs, letting `[QA-Telemetry]` compare Rust traces against the degraded navigator (`[TS-B3]`, `[TS-B4]`).
4. **Publish MetricAdapter + TreeBuilder tracer design** – `[TS-B2]` now tracks injecting the new `TreeBuilderTracer` into `TreeBuilder` and capturing Stage D slice traces; document the adapter plan so M4 can switch safely.
5. **Wire up Breaks/Diff/Search exporters** – CLI/schema/manifest 规范已落在 `[StageD::FixtureFlow]`、`[StageD::ParityAssets]`、`fixtures/parity-fixture-schema.md`；下一步是实现 `export-serde-fixtures` flag（`--breaks-descriptors`, `--diff-regions`, `--search-spans`）、写入 manifest，并在 `scripts/refresh_*` 中启用这些资产 (`[TS-B5]`).
6. **[Done – 2025-11-19] Stand up C# Breaks/Diff/Search skeletons** – C# Implementer delivered `Rope/Breaks/BreaksTree.cs` (`BreakPlan`/`BreakBuilder`), `Diff/DiffBuilder.cs` + companions, and `Search/Finder.cs` + options/results along with smoke tests executed via `dotnet test Xi.Editor.sln -v m --filter "BreaksSkeletonTests|DiffSkeletonTests|SearchSkeletonTests|StageDDescriptorLoaderTests"`; focus now shifts to implementing the actual algorithms and wiring the Stage D loader/manifest ingestion paths so QA can exercise real payloads.
