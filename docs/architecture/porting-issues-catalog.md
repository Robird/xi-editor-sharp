# 移植问题清单与分类

## 简介 / 目标 / 适用范围
- 为 Rust ↔ C# Rope / Mini Blocking Model 之间的高风险语言特性提供单一事实来源，保证 `AGENTS.md`、“Mini Blocking Model”计划（`docs/architecture/mini-blocking-model-plan.md`）、`docs/architecture/m3-implementation-plan.md`、`docs/architecture/type-system-migration-log.md` 与 `docs/architecture/fixtures/parity-fixture-schema.md` 的结论一致。
- 当前覆盖 SharedNode/COW、NodeCursor + `_editVersion`、`cursor_state` feature gate、chunk/line 与 grapheme 描述符、TreeBuilder trace CLI、`helpers/string_leaf.rs`、Delta/Subset/TreeBuilderTrace serde-less fixture等阻塞点；如 `BlockingPointRegistry`（`blocking-model/csharp/BlockingModel.Core/Class1.cs`）新增条目应同步扩展此文档。
- 读者：Architecture Mapper、Rust Porter、C# Implementer、QA Engineer 以及维护 `scripts/refresh_serialization_fixtures.ps1` 与 parity fixture exporter 的协作者，便于快速定位风险、验证脚本与 mini workspace 协作点。
- 引用的模块/脚本均以仓库相对路径或 CLI 名称呈现；查阅条目时请同时打开对应测试（例如 `tests/xi.Core.Tests/*.cs`、`blocking_model_core/tests/*.rs`）确认事实。

## 分类方法
本清单采用三层标签体系；每个条目以主类别为准，可在描述/风险中引用次级维度。

| 层级 | 类别代号 | 维度说明 | 典型关注点 |
| --- | --- | --- | --- |
| L1 语言/内存语义 | `O` Ownership & Lifetime | 借用、COW、Arc/引用语义、版本票据 | `SharedNode`, `NodeCursor`, `_editVersion` |
| L2 类型系统/Helper | `M` Metric & Leaf, `S` Serialization / Parity Helper | 泛型接口、度量转换、Breaks tree、Delta/Subset helper | `helpers/string_leaf.rs`, `Delta::iter_elements`, `BreaksTree` |
| L3 运行时/CLI/Telemetry | `T` Trace & Diagnostics（含 CLI/Telemetry）, `F` Feature Gate & Runtime Toggles | Trace CLI、chunk/line/grapheme 描述符、遥测、feature 组合 | `tree_builder_slice_trace`, `export-tree-builder-trace`, `chunk_descriptors`, `cursor_state`, `GraphemeTelemetry` |

> 使用方式：在条目表中通过 `类别` 列标记主类别（例如 `O`, `T`），必要时在描述/风险中指出关联的次级维度或关联 `BlockingPointKind`。
